# 纪念 · 双身份工作台

一个本地优先、可安装、双端同步的工作台：
- **甘肃鼎天测控科技（老板）** —— 记录公司财务（收入 / 支出 / 类别 / 结余）
- **甘肃翰亚科技（项目经理）** —— 记录出差开销与补助（自动算天数与补助总额）

同一份数据在**手机和电脑之间自动同步**。无需上架应用商店：手机用浏览器"添加到主屏幕"即变成 App。

## 项目结构
```
workbench/
├─ server/            # Node 同步服务器（同时托管网页）
│  ├─ server.js
│  ├─ package.json
│  └─ data/records.json   # 同步数据自动落盘
└─ public/            # 前端（PWA）
   ├─ index.html  styles.css  app.js
   ├─ manifest.webmanifest  sw.js  icon.svg
```

## 运行（电脑端）
需要 Node.js（>=16，本机已带）。
```bash
cd workbench/server
node server.js
```
启动后：
- 电脑打开： http://localhost:3000
- 手机连接：点电脑页面右上角 **📱 连手机** → 用手机扫二维码即可打开（手机和电脑需连**同一个 WiFi**）。二维码里的地址会自动检测电脑当前局域网 IP。

## 同步原理
- 网页同时由 Node 服务器托管，前端与 `/api/records` 同域通信，天然跨设备同步。
- 每条记录带 `updatedAt` 时间戳，采用"后写覆盖"合并；手机和电脑任意一端新增/修改/删除，点"同步"或保存时自动互相同步。
- 离线时数据先存手机/电脑本地，联网后自动补齐。

## 电脑 IP 是自动获取的、每次都变，怎么办？
每次 DHCP 续租后 IP 会变，**不影响同一次开机内的使用**（手机扫码用的是当前 IP）。想让地址**永远固定**，二选一：

**方案 A（推荐，最简单）：把电脑 IP 设成静态**
1. 电脑连上 WiFi/网线，先看当前 IP（命令提示符 `ipconfig` → IPv4，例如 `192.168.10.3`）。
2. 记下：IP 地址、子网掩码（如 255.255.255.0）、默认网关（如 192.168.10.1）。
3. 控制面板 → 网络和共享中心 → 更改适配器设置 → 右键正在用的"以太网/WLAN" → 属性 → 双击"Internet 协议版本 4 (TCP/IPv4)" → 选"使用下面的 IP 地址"，填入上面记的地址（建议把最后一段改成 100 以上，避开路由器自动分配段，如 `192.168.10.100`）→ DNS 填 `223.5.5.5` 和 `119.29.29.29` → 确定。
4. 之后手机地址固定为 `http://192.168.10.100:3000`（在 📱连手机 浮层里可从下拉切换确认）。

**方案 B（不改电脑，让路由器记住）：DHCP 保留**
登录路由器管理页（浏览器开网关地址如 192.168.10.1），找到"DHCP 保留/静态分配"，把电脑的 MAC 地址绑定到一个固定 IP。效果同方案 A，且电脑仍用自动获取。

> 设成静态后，手机二维码/地址就永久不变了，以后直接打开书签或重扫一次即可。

## 部署到免费云（推荐：解决笔记本关机问题）
把"同步服务器"部署到永远在线的云平台后，手机和电脑**随时随地都能同步**，不再依赖笔记本开机。

本项目已做成**云就绪**：
- 服务器 `server/server.js` 读取 `process.env.PORT` 并绑定 `0.0.0.0`
- 有 `package.json`（根目录，`start: node server/server.js`）、`Procfile`
- **双存储自动切换**：设置了 `DATABASE_URL` 环境变量 → 用 PostgreSQL（云端持久）；没设 → 用本地 JSON 文件

👉 **完整图文步骤见 `DEPLOY.md`**（已选方案：GitHub + Koyeb，免绑卡，且 Koyeb 送免费 PostgreSQL，数据重部署不丢）。

### 关于云端数据持久化
- 云端用 PostgreSQL 时数据持久，重部署不丢；
- 每个设备本地也保留完整副本，云端异常时会自动回退到本地文件并继续运行；
- 仍建议定期用网页底部「导出备份」下载 JSON 留底。

## 数据备份
网页底部有"导出备份 / 导入备份"，可随时导出 JSON 留底。本地模式下服务器 `server/data/records.json` 也是完整数据文件。

## 自定义
- 财务类别、补助标准等直接在页面下拉框/输入框调整。
- 想改端口：`PORT=8080 node server/server.js`
